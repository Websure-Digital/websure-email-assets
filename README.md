# Websure email assets

Public images for Websure email signatures and email templates, served by GitHub Pages at
`https://websure-digital.github.io/websure-email-assets/`.

Images only. No documents, no contact details, no keys. Every file here is something that already goes out in Websure emails.

The source (the signature generator and team list) lives in the Websure brand project, not here. To change an image, rebuild it there and replace the file here with the same name.
